<objective>
Close UX-08's open half: four procedural machines are gated on ownership but on nothing else, so an owned Shaker drives around the orchard in Winter. Add a `currentPhase` condition alongside the existing ownership condition, backed by a mapping derived from each machine's real in-game function.

Purpose: the requirement always said "visible only when the player owns the corresponding infrastructure **and during the phase it would plausibly operate**." Half of it shipped. The visible symptom is a harvester working a dormant winter orchard, which undercuts the whole diorama the rest of this phase is building.

Output: a typed, testable mapping module, a reordered and gated `orchardAutomationConfig`, a 40-case truth table, and a harness that can be driven to any phase from the URL.
</objective>
