<objective>
Fix UX-04: the dashboard sidebar's running-costs box renders a fabricated `0 PLN` survival budget forever in guest/demo mode, because the component branches only on `isLoading`, which React Query v5 reports as `false` for a disabled query.

Purpose: a player in guest mode is being shown a confident financial figure that is not merely stale but never existed. That is worse than a spinner — it is wrong data presented as right. The audit called these "never-resolving placeholder boxes"; the corrected diagnosis is a silent fallthrough, and the fix is the same either way: an explicit guest state.

Output: a four-branch RunningCosts (guest / loading / error / data) following the `SportsCenter.tsx` pattern already proven in this codebase, plus the component test that pins all four.
</objective>
