<objective>
Delete the dead `GameLogic.calculateSpoilageRate` (zero call sites), leave `StorageLogic.calculateSpoilage` as the single spoilage system, and rewrite the design doc so it documents the formula that actually runs.

Purpose: two spoilage systems coexist and the one the documentation describes is the one nothing calls. A reader — human or agent — following `spoilage-rates.md` today gets numbers (100% / 80% / 20% by infrastructure) that the game has never applied. That is worse than no doc.

Output: one spoilage implementation, one accurate doc, and a ratchet that stops a second one appearing.
</objective>
