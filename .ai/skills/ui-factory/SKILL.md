# UI Factory Skill — Neo-Steampunk Cherry

🎯 **Purpose**: 
Maintain visual consistency across all frontend views by enforcing the "Golden Harvester" design system. Every component must feel like a physical part of brass-punk machinery, not a flat digital overlay.

🛠️ **Implementation Logic**:
- **Design Pillars**: Skeuomorphism 2.0 (Brass/Gold), Emerald Core (Glow), God Rays (Depth), Haptic Visuals.
- **Tokens**: `brass` (#C9A84C), `copper` (#B36A2A), `ruby` (#8B1A1A), `emerald-glow` (#00FF88).
- **Mandatory Classes**: `.mechanical-hull`, `.hull-header`, `.god-ray`.

🗣️ **Usage Rule**:
Activate via `/ui-factory [component]`. 
Handshake: `"Handshake Verified: ui-factory applied. Neo-Steampunk standard enforced."`

## Workflow:

1. **Read Concept**: Review `references/game_lore.md` and `references/ui-consistency.md`.
2. **Setup Layer**: Determine if particle layer is needed (ping `/particles`).
3. **Lore Check**: If AI-rival involved, trigger `/lore-guardian [character]`.
4. **Generate**: Create React components using `.mechanical-hull` standard and `brass-rim` shadows.
5. **Asset Verification**: Check if custom textures from `assets/` or Nano Banana 2 are required.
6. **Handshake**: Verify 60 FPS mobile performance and skeuomorphic depth.
